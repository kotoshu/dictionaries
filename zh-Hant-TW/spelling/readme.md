# zh-Hant-TW spelling wordlist

61,239 Taiwan-traditional words. Built from the wordfreq zh list,
converted via OpenCC s2tw and validated against g0v/moedict-data
(Taiwan MOE) plus the CC-CEDICT traditional column (plan C3,
models-fasttext-onnx).

zh-Hant-HK is an explicit gap: no HK-specific open frequency source
identified yet; it is NOT faked with TW data (variant separation rule).
